ORIGO

複素数平面の格子点で戦う、変換の対局。1局 5〜10 分。

z′ = c + w(z − c)
  • 核以外の駒は、味方の駒 c を中心にした変換（回転・拡大縮小・対称移動・複素数倍）で跳びます。途中の駒は関係ありません。
  • 跳んだ先に相手の駒があれば取ります。味方が減ると中心も減り、動きが痩せます。
  • 相手の核を詰めるか、自分の核を原点 O に置いて相手の 1 手をしのげば勝ち。

CPU の強さ

手番

ルール

盤は複素数平面の格子点 x + yi（x, y は −3〜3 の整数）、全 49 点。

進め方

  • 交互に、自分の駒を 1 つ動かします。パスはできません。
  • 移動先に相手の駒があれば取ります。味方の駒がある点には動けません。
  • 自分の核が取られる状態になる手、同じ局面を 3 回目にする手は指せません。

勝敗

  • 詰み：相手に指せる手がなくなれば勝ち。
  • 原点制圧：自分の核を原点 O に置き、相手が次の 1 手でその核を狙えなければ勝ち。狙われたら通常どおり受けます（相手の利きがある間は原点に入れません）。
  • 120 手で決着しなければ引き分け。

駒の動き

核以外の駒は、味方の駒のどれか 1 つを中心 c に選び、自分の位置 z を次の式で移します。行き先が格子点で盤内なら跳べます（途中に駒があってもよい）。

核z′ = z + u　u = 1, i, −1, −i（上下左右に 1）
回転子 iz′ = c ± i(z − c)　c を中心に ±90° 回転
拡大子 kz′ = c + k(z − c)　k = 2, −2, ½, −½, −1。c から見て同じ直線上を伸縮。k = −1 は点対称、½ は中点
鏡映子 z̄c を通る 横・縦・傾き ±1 の直線に関して対称移動。式では c ± z − c、c ± i·z − c
螺旋子 1+iz′ = c + (1 ± i)(z − c)：±45° 回転して √2 倍。逆向きの ½(1 ± i) 倍（±45° 回転して 1/√2 倍）も可

読みのコツ

  • 駒を 1 つ動かすと、それを中心にしていた味方すべての行き先が変わります。
  • 相手の攻め駒が取れなくても、中心になっている駒を取れば攻めは消えます。
  • 相手の駒に触れると、その駒が次に跳べる点を確認できます。

棋譜コード

手番・乱数の種・手順だけで、この対局を最初から再現できます。
